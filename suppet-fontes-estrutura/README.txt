SUPPET — ESTRUTURA DE FONTES PARA SERVIDOR

Por segurança/licenciamento, este pacote não inclui os arquivos binários das fontes.

Fontes usadas no projeto:
- Baloo 2: pesos 500, 600, 700 e 800
- Nunito Sans: pesos 400, 600, 700 e 800

Depois de baixar os arquivos .woff2 das fontes em suas fontes oficiais, coloque-os nestes caminhos:

fonts/baloo-2/baloo-2-500.woff2
fonts/baloo-2/baloo-2-600.woff2
fonts/baloo-2/baloo-2-700.woff2
fonts/baloo-2/baloo-2-800.woff2
fonts/nunito-sans/nunito-sans-400.woff2
fonts/nunito-sans/nunito-sans-600.woff2
fonts/nunito-sans/nunito-sans-700.woff2
fonts/nunito-sans/nunito-sans-800.woff2

Use o arquivo fonts.css incluído neste pacote.
